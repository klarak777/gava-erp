# Kiadási Jegyzetek és Telepítési Útmutató (Release Notes) - V0.9.3

**Kiadás Dátuma:** 2026. Szeptember 20.

Ez a dokumentum az elmúlt 12 órában végzett módosításokat, fejlesztéseket és hibajavításokat tartalmazza, valamint egy lépésről-lépésre szóló útmutatót az éles (DO) szerverre történő telepítéshez (deployment).

---

## 🚀 Fejlesztések és Új Funkciók

1. **Több raklap támogatása a Komissiózásnál (PDA UI & Backend)**
   - A PDA komissiózási felületén (űrlap) a felhasználó mostantól egy Megadás gombbal rögzítheti a tételeket.
   - Új funkció: Több raklap kiválasztása egyetlen komissiózási tételhez. A legördülőből kiválasztott raklapok a + Raklap gombbal hozzáadhatók egy dinamikus listához. Nincs előre kiválasztott alapértelmezés.
   - A nettó súly számításánál a rendszer az összes megadott raklap tára súlyát figyelembe veszi és levonja a bruttó súlyból.
   - Kialakításra került a pallets_json adatbázis mező az ldi_commission_lines és az sscc_labels táblákban. Ez a mező JSON formátumban tárolja az összes kiválasztott raklap pontos nevét, kategóriáját és tára súlyát.
   - A komissiózás API (pda.js) mostantól pallet_types nevű tömböt fogad.

2. **Raklapcímkék Modul Frissítése (Admin UI)**
   - A raklapcímkék táblázatából eltávolításra került a felesleges ID oszlop.
   - Új Raklap típus oszlop került bevezetésre.
   - Ha egy címkéhez több raklap tartozik, a rendszer az összeset felsorolja a cellán belül Név (Súly kg) formátumban.
   - A backend API (dmin.js) frissült: LEFT JOIN segítségével biztosítja a visszamenőleges kompatibilitást. A régi (még nem JSON-ben tárolt) adatokhoz a komissiózási sorokból visszatölti a raklap kategóriát és a tára súlyt, XSS biztonságos megjelenítéssel.

3. **Karton Számítás Pontosítása (PDA UI)**
   - A PDA komissiózási felület fejlécében mostantól nem a teljes megrendelt mennyiség jelenik meg, hanem a **hátralévő, még komissiózandó kartonszám**, valamint külön kiírásra kerül a tétel össz-kartonszáma.
   - A beviteli mező (placeholder) kitisztítva, a zavaró előredefiniált szövegek eltávolítva.

## ⚙️ Telepítési Útmutató (DO Szerver / Élesítés)

A projekt a szerveren Docker Compose környezetben fut. A következő parancsok futtatása szükséges az élesítéshez.

**1. Lépj be a szerverre SSH-n keresztül, és navigálj az ERP projekt mappájába:**
`ash
ssh user@do_server_ip
cd /utvonal/a/projekt/mappaba/gava-erp
`

**2. Frissítsd a forráskódot a GitHub-ról:**
`ash
git pull origin master
`

**3. Futtasd az adatbázis migrációkat a backend konténeren belül:**
*(Megjegyzés: A gava_erp_prod_api a docker-compose.prod.yml fájlban definiált backend API konténer neve)*
`ash
docker exec -it gava_erp_prod_api npm run migrate
`

**4. Indítsd újra a backend és frontend konténereket (vagy buildeld újra őket):**
Mivel a Node.js forráskód módosult, és a frontend UI statikus fájljai is változtak, újra kell építeni a konténereket.
`ash
docker-compose -f docker-compose.prod.yml up -d --build
`

**5. Ellenőrizd a naplófájlokat, hogy minden rendben elindult-e:**
`ash
docker logs -f gava_erp_prod_api
`
